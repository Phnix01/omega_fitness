## 🚀 Prochaines étapes (facile)

### Étape 1 : Configuration Web3Forms (5 min)
1. Allez sur [web3forms.com](https://web3forms.com)
2. Créez un compte gratuit
3. Copiez votre Access Key
4. Remplacez `YOUR_ACCESS_KEY_HERE` dans [index.html](index.html) :
   - Ligne 356 (formulaire réservation)
   - Ligne 462 (formulaire contact)

### Étape 2 : Personnalisation (10 min)
1. Modifiez vos coordonnées dans [index.html](index.html)
2. Ajustez les tarifs si nécessaire
3. Changez les couleurs dans [style.css](style.css)
4. Mettez à jour la carte Google Maps

### Étape 3 : Test local (2 min)
1. Ouvrez [index.html](index.html) dans votre navigateur
2. Testez les formulaires
3. Vérifiez sur mobile (F12 → mode responsive)

### Étape 4 : Déploiement (10 min)
1. Créez un compte [Netlify](https://netlify.com) (gratuit)
2. Glissez-déposez le dossier
3. Votre site est en ligne ! 🎉

**Total : 30 minutes pour un site professionnel**
